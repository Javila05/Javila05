## 👨‍💻 Sobre mí

💼 Soy Software Developer con experiencia trabajando en **sistemas empresariales de facturación y procesos aduanales para DHL Guatemala y Caribe**, dando soporte a soluciones utilizadas en más de 20 países.

⚙️ Mi trabajo combina backend, bases de datos e integraciones, utilizando principalmente **C#/.NET y SQL Server** para implementar reglas de negocio, resolver incidencias y evolucionar procesos empresariales existentes.

🗄️ Tengo experiencia trabajando directamente con **Stored Procedures, consultas SQL, validaciones, procesamiento de datos e interfaces entre sistemas**, dentro de entornos donde la precisión de la información y la continuidad de los procesos son especialmente importantes.

🌐 También desarrollo soluciones full stack y disfruto especialmente el **frontend**, área en la que cada vez busco mejorar más. Me gusta transformar requisitos funcionales en interfaces modernas, responsivas y visualmente cuidadas utilizando **React, Next.js, Tailwind CSS, GSAP y otras tecnologías modernas**.

🚀 Mi objetivo es seguir creciendo como desarrollador capaz de entender una solución de extremo a extremo: **base de datos, backend, integraciones, arquitectura y experiencia de usuario**.
